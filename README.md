# Data Science od podstaw (Joel Grus)

Repozytorium zawiera implementacje zagadnień i algorytmów z książki *„Data Science od podstaw. Nauka o danych od podstaw”* (ang. *Data Science from Scratch*) autorstwa Joela Grusa.

## Idea przewodnia

Głównym celem jest zrozumienie zasad działania narzędzi Data Science poprzez samodzielne pisanie algorytmów od zera (tzw. podejście *first principles*) w czystym Pythonie, z minimalnym użyciem gotowych bibliotek uczenia maszynowego (takich jak scikit-learn).

## Zakres tematyczny

1. **Podstawy matematyczne i narzędziowe**
   - Wektory i macierze (algebra liniowa)
   - Statystyka opisowa, korelacja i paradoks Simpsona
   - Prawdopodobieństwo i rozkłady losowe
   - Testowanie hipotez i wnioskowanie statystyczne
   - Metoda spadku gradientu (Gradient Descent)

2. **Pozyskiwanie i przygotowanie danych**
   - Web scraping (BeautifulSoup)
   - Praca z API i formatami JSON/CSV
   - Czyszczenie, manipulacja i eksploracja danych

3. **Uczenie maszynowe (Machine Learning)**
   - K-najbliższych sąsiadów (k-NN)
   - Naiwny klasyfikator bayesowski (Naive Bayes)
   - Regresja liniowa i regresja wieloraka
   - Regresja logistyczna
   - Drzewa decyzyjne i lasy losowe

4. **Zaawansowane zagadnienia**
   - Sieci neuronowe i wsteczna propagacja błędów
   - Przetwarzanie języka naturalnego (NLP) oraz n-gramy
   - Grupowanie (k-średnich)
   - Analiza sieci społecznościowych i PageRank
   - Systemy rekomendacyjne
   - Praca z bazami danych (SQL i map-reduce)

## Nabyte umiejętności

- **Zrozumienie działania modeli:** Wiedza, co dzieje się wewnątrz algorytmów ML bez traktowania ich jako „czarne skrzynki”.
- **Implementacja od podstaw:** Umiejętność przełożenia wzorów matematycznych i probabilistycznych na działający kod.
- **Optymalizacja i matematyka:** Praktyczne stosowanie rachunku macierzowego i optymalizacji numerycznej.
- **Inżynieria danych:** Samodzielne pobieranie, przetwarzanie i przygotowywanie danych do analizy.
